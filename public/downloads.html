Cliente roBrowserLegacy com mapas, sprites, animações e movimento por clique do Ragnarok. O servidor rAthena salva personagens e reúne os jogadores no mesmo mundo.

Windows

Windows 10/11 · 64 bits

Baixar instalador Ragnarok

Execute o instalador e abra o atalho Quest Ragnarok. Atualização 2.0.1: corrige a abertura dos mapas no Windows e reutiliza os arquivos kRO já baixados. O jogo abre em uma janela do Edge, quando disponível.

macOS

macOS 12+ · navegador com WebGL

Baixar para Apple Silicon

Baixar para Intel

Extraia o ZIP e mova Quest Ragnarok.app para Aplicativos. O cliente abre no navegador padrão.

Conexão ao mundo

Criar conta Ragnarok

Na primeira execução, o cliente baixa aproximadamente 4 GB de dados kRO e verifica SHA-256. Reserve 6 GB de espaço livre.

Confira no portal do jogo a disponibilidade e o endereço atual do servidor para informar no aplicativo.

No iPad, abra o portal pelo Safari e use Jogar agora quando o servidor estiver disponível.

Hospedar no seu Windows

Pacote do servidor rAthena com banco MariaDB persistente. Requer Docker Desktop com WSL2.

Baixar pacote do servidor

No repositório Quest do seu computador, atualize main e execute scripts\IniciarServidorWindows.cmd. Consulte LEIA-ME.md no pacote para configurar a rede local ou o domínio público.
